# Support

## Getting Help

If you need help with gh-agent-funhouse, here are the best ways to get support:

### Documentation

- **[Online Docs](https://mxn2020.github.io/ghuru/)**: Full documentation including setup guides, architecture, and API reference.
- **[README](README.md)**: Quick start guide and overview.

### Community

- **[GitHub Issues](https://github.com/mxn2020/ghuru/issues)**: Report bugs or request features.
- **[GitHub Discussions](https://github.com/mxn2020/ghuru/discussions)**: Ask questions, share ideas, and connect with other users.

### Bug Reports

When filing a bug report, please include:

1. Your operating system and Python version
2. The command you ran and its full output
3. Steps to reproduce the issue
4. Expected vs actual behavior

### Feature Requests

We welcome feature requests! Please check existing issues first to avoid duplicates, and include:

1. A clear description of the feature
2. The problem it solves or use case it enables
3. Any relevant examples or mockups

## Security Issues

For security vulnerabilities, please see [SECURITY.md](SECURITY.md) for responsible disclosure guidelines.
